Quice Win32 MaNGOS WoTLK (3.3.5) aka Mangos Two DataBase Editor
=====
Quice is a database editor made for editing MaNGOS DB.

You can edit quests, creatures, gameobjects, items, loot and some minor things.

It is written on Delphi, source on github compiled using 
Embarcadero Delphi 11/12 and the source is available on 
https://github.com/chaosua/quice 
It is backport from Truice https://github.com/chaosua/Truice

Tested on 8203c818722eecca91dcb774aae5389bc98f68e4 commit
https://github.com/mangostwo/database
